# Elegance Beauty Studio

Site static demonstrativ pentru un salon fictiv de înfrumusețare. Proiectul folosește HTML, CSS și JavaScript simplu, fără biblioteci sau proces de compilare.

## Deschidere

1. Deschide folderul `elegance-beauty-studio` în File Explorer.
2. Dă dublu clic pe `index.html` pentru a-l deschide în browser.

Nu este necesară instalarea unui program sau pornirea unui server local. Pentru fotografii și fonturi este necesară o conexiune la internet; fără conexiune, pagina rămâne utilizabilă, dar browserul va folosi fonturile alternative și imaginile pot lipsi.

## Structură

- `index.html` — conținutul și structura semantică a paginii.
- `styles.css` — paleta, aspectul responsive și animațiile.
- `script.js` — meniul pentru mobil, linkul WhatsApp, anul din subsol și aparițiile la derulare.

## Conținut demonstrativ

Elegance Beauty Studio este fictiv. Adresa, programul și tarifele sunt exemple, iar imaginile sunt fotografii demonstrative găzduite de Unsplash; nu reprezintă locația sau lucrările unei afaceri reale.

Butonul WhatsApp deschide WhatsApp cu un mesaj pregătit, fără un număr de telefon prestabilit. Utilizatorul trebuie să aleagă conversația sau destinatarul.
